# 模拟案例 / Synthetic cases

以下材料完全为测试设计，不对应真实论文、DOI 或科研结论。用于观察 skill 是否保留证据边界，不用于证明科研准确率。

## 1. 细胞结果被外推到人体疗效

输入结论：“药物 A 能降低患者心衰死亡率。”

提供材料：一段模拟的完整原始研究说明，只研究培养的小鼠心肌细胞；三次独立分离，每次六个视野。A 处理后细胞存活率上升；没有患者、死亡率或临床随访。

应保留：三次分离与视野层级；测量结局是细胞存活率。对输入的患者死亡率主张，标为间接相关，临床证据不足。可改为“在该细胞模型及实验条件下，A 提高了细胞存活率”。不能报十八个独立生物学重复或临床有效。

## 2. 受体依赖被写成直接结合

输入结论：“蛋白 A 直接结合受体 B，并通过 B 改善心功能。”

提供材料：模拟小鼠干预实验报告功能改善；B 缺失后效应减弱。有干预和缺失对照，未报告救援、结合实验或缺失的其他生理影响。另有对接预测，未验证。

应保留：拆开功能效应、B 依赖和直接结合。讨论缺失特异性和补偿等替代解释。对接不能升级为结合实证；B 依赖不能升级为直接结合。不要给整句一个强支持标签。

## 3. 来源全文不可得与引用语境未定位

输入：来源论文标题和结论句；来源仅有参考文献表。检索返回一篇相关原始研究的摘要，全文获取失败；另一相关论文由独立关键词检索发现。

应保留：论文级引用关系与句子级引用语境分开。全文失败不是零结果。独立发现不连接成原始引用链；摘要声称支持不升级为核实直接支持；未找到反对结果不等于证据一致。

## 4. 表面冲突与不显著结果

输入结论：“A 在成年动物中提高心功能。”

提供材料：模拟研究一使用成年动物、低剂量、四周和射血分数；研究二使用幼年动物、高剂量、两天和细胞标志物，方向相反；研究三为成年动物同类结局，效应区间较宽且跨过零。

应保留：研究二可比性有限，不自动标为明确反证。研究三统计不显著不证明零效应，报告区间与精度限制。输出保留不同条件和不确定性。
